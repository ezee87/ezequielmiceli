# Paquete Claudia Sánchez para Sonnet

1. `01-COPY-WEB.md`: copy íntegro y mapa de las seis secciones de la página funcional, CTA obligatorio.
2. `02-PROPUESTA-COMERCIAL.md`: estructura y copy de la propuesta comercial abreviada (con campos comerciales sin inventar).
3. `03-DIRECCION-VISUAL-ANIMACION-Y-TECNICA.md`: tokens, efectos, asignación de skills y QA.
4. `04-PROMPT-MAESTRO-SONNET.md`: instrucciones para Copilot/Sonnet. Entregar todos los documentos junto al prompt.

## Cómo usar

Copiá los cuatro archivos `.md` a `docs/claudia/` dentro del repositorio (conservar nombres) y pegá a Sonnet el contenido del prompt maestro, o pedile que lea `docs/claudia/04-PROMPT-MAESTRO-SONNET.md` y lo ejecute. El prompt asume que las skills del starter están instaladas y deben verificarse.
